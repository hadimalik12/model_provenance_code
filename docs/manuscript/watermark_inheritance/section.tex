\subsubsection{Controlled Watermark-Inheritance Experiment}
\label{subsubsec:watermark-inheritance}

\myparatight{Setup}
We test whether a deliberately introduced shard signal survives downstream
fine-tuning, adapting watermark radioactivity~\citep{sander2024watermarking}.
In each of three runs with distinct watermark keys and random seeds, a frozen
Pythia-1B generates $10{,}000$ pairs of independently sampled watermarked
completions from WikiText prompts. Within each pair, both completions use the
same prompt and key and are randomly assigned to $S$ and $S'$.
We fine-tune the base model $B$ on the completion tokens in $S$ to obtain
$P(S)$, then separately fine-tune this parent on Dolly 15K or UltraChat to
obtain $T$. The control $T_0$ receives the corresponding downstream training
directly from $B$; $S'$ is never used for model training.

\myparatight{Distinguisher construction}
The watermark reading-mode score measures agreement between the audited
model's next-token predictions on stored text and the watermark greenlists.
For each checkpoint, we calibrate a score threshold on $2{,}000$ pairs and
audit the remaining $m=8{,}000$ pairs. These pairs are held out from calibration;
their $S$ completions were used to train $P(S)$.
We report balanced accuracy $(1+\widehat{\Delta})/2$ and the signed gap
$\widehat{\Delta}=a-a'$, rejecting when
$\lvert\widehat{\Delta}\rvert>\gamma^{\mathrm{pair}}_{0.05}$.
For independent, mean-zero pair differences under $H_0$, the conservative
paired threshold is
$\gamma^{\mathrm{pair}}_{0.05}=\sqrt{2\log(2/0.05)/m}=0.0304$.
Checkpoint comparisons are descriptive, without simultaneous error control.

\myparatight{Results and interpretation}
\Cref{tab:watermark_dolly_results} reports every Dolly target epoch; only the
epoch-three control was audited, so its result is repeated within each run.
All targets reject $H_0$, with final advantages $0.5906$--$0.6160$.
\Cref{tab:watermark_ultrachat_results} reports the distinct-example UltraChat
snapshot through $400{,}000$ examples, with controls matched at each checkpoint.
Advantages generally decrease but remain $0.3124$--$0.3228$ at the last reported
checkpoint. All controls fail to reject $H_0$.
The planned $600{,}000$-example endpoint is not complete in this snapshot.
These results support shard-signal inheritance through downstream fine-tuning;
the Dolly--UltraChat comparison changes both corpus and exposure.
